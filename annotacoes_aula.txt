------------ Conhecendo os Componentes ------------

Authorization Server -> Autentica e Identifica o Usuario e o Client (ambos precisam estar cadastrados e registrados),
possui a base de dados dos usuarios e clients

Resource Server -> Dados que serão acessados (API), pode ter as regras de acesso (roles...)

Usuario -> Quem está acessando o sistema

Client -> Sistema cadastrado que irá requisitar os dados

------------ Geral ------------

Usuario acesa o Resource Server através do Client, Client se precisar autenticar vai pedir pro Authorization Server
autenticar o Usuario, Usuario esse que vai se autenticar e que o TOKEN será emitido para o Client acessar os dados do
Resource Server
