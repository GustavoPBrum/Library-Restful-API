<------------ Aula 150 - Como obter Token JWT Utilzando Client Credentials (Grant Type) ------------ >

Criamos no Postman Client Credentials, que autentica de uma API para a outra. Uma API acessando outra. Sem usuario
digitando Login e Senha.

Vimos a forma utilizando o Postman no qual ele deixa de fácil manuseio de ser feito nosso Client Credentials, mas agora
farei as anotações de um Client Credentials de maneira manual e sem usar as indicações do próprio Postman.

Criamos um segundo Folder do Client Credentials - Manual:
-> Authorization:
De 'OAuth 2.0' para 'No Auth'

-> Headers:
Adicionamos a KEY 'Authorization' e Value será o 'Basic (...)' -> Base64 do clientId e clientSecret

-> Body:
'None' para 'x-www-form-urlencoded' com KEY 'grant_type' e Value 'client_credentials' e outra KEY 'scope' e Value
'GERENTE'

Método HTTP 'POST' com url 'http://localhost:8080/oauth2/token' e por que está URL? Pois é a URL PADRÃO, independente do
*Authorization Server* utilizado!!!

Podemos verificar o Token no site 'https://www.jwt.io/'

Pode-se utilizar este Token gerado por exemplo na pesquisa de livros:

-> Authorization:
'Bearer Token' para 'No Auth'

-> Header:
Criada a KEY 'Authorization' com Value 'Bearer (...)' com o código do Token
