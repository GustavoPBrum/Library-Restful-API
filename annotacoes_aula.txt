<------------ Aula 135 - Customização Autenticação Google ------------>

-------- O que foi feito --------

Estratégia para receber os dados do usuario autenticado do Google, transformando em CustomAuthentication

No SecurityConfiguration fizemos:
// Quando fizer uma autenticação com sucesso, chama a classe informada
.oauth2Login(oauth2 ->
    oauth2.successHandler(???))

Receberemos nossa Authentication a transformando em CustomAuthentication

Criamos a Classe loginSocialSucessHandler, com @Component e @RequiredArgsConstructor. Receberemos a Authentication
do Google, mas iremos no BD buscar o Usuario atraves do email do Google.

loginSocialSucessHandler extends SavedRequestAwareAuthenticationSuccessHandler que é uma implementação de
AuthenticationSuccessHandler

A interface (SuccessHandler) tem o método onAuthenticationSuccess com paramêtros request, response, authentication

loginSocialSucessHandler foi injetado no SecurityFilterChain (SecurityConfiguration)
.oauth2Login(oauth2 ->
    oauth2.successHandler(successHandler))

Agora no método onAuthenticationSuccess:

    // Usuario do Auth2
    OAuth2User oAuth2User = oAuth2AuthenticationToken.getPrincipal(); // Authentication Google

    String email = oAuth2User.getAttribute("email");  // Pegando email do usuario autenticado do google
    Usuario usuario =  service.obterPorEmail(email); // Método também criado no usuarioService/usuarioRepository

    authentication = new CustomAuthentication(usuario);  // UpperCasting

    // Adicionando CustomAuthentication no contexto (no lugar da oAuth2AuthenticationToken)
    SecurityContextHolder.getContext().setAuthentication(authentication);

    // Passa pra frente/da continuedade na requisição
    super.onAuthenticationSuccess(request, response, authentication);

** Com isso TODAS as minhas Authentication são instâncias de CustomAuthentication**
