<------------ Aula 148 - O que é um Token JWT? ------------ >

JWT -> JSON WEB TOKEN, para trabalhar com aplicações WEB

OAuth2 SÓ DEFINE que irá utilizar TOKENS!!  Token mais utilizado é o JTW!!!

Podemos ter Token Opacos.

Token JWT -> Carrega informações

Token Opacos -> Um Hash que não diz nada!!! Apenas letras e números (valida apenas se existe ou não o Token no servidor)

------------ Anatomia Token JWT ------------

Possui 3 partes, Header, Payload(corpo) e Verify Signature

Header: Possui alguns meta dados, tipo do Token, algoritmo utilizado para gerar a assinatura...

Payload: Carrega as informações customizadas! sub (subject, geralmente ID do usuario, identificação do usuario), name,
iat (Issued at, quando foi emitido o Token)

**Informações colocadas no Payload são chamadas de CLAIMS**

Claims do Token -->> Informações do Token

Verify Signature -> Parte que não conseguimos descriptografar sem a chave que foi usada para assinar este Token
